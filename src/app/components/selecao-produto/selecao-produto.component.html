Desenvolva um componente SelecaoProdutoComponent que exiba uma lista de produtos fornecida pelo componente pai através de Input. Cada produto deve ter um botão "Selecionar". Ao clicar nesse botão, o componente deve emitir um evento usando Output para informar ao componente pai qual produto foi selecionado, passando o objeto do produto como parâmetro.
